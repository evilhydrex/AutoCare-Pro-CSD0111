## Project description
AutoCare Pro is a beginner-level browser application for managing spare-parts inventory and preparing simple customer invoices for an automobile service station.

## Technologies
- HTML: website structure and forms
- CSS: layout, colours and responsive styling
- JavaScript: inventory operations, billing, validation and reports
- LocalStorage: saves data in the browser
- MS Excel: sample inventory data, formulas and charts
- MS Word: project report
- MS PowerPoint: project presentation

## Features
1. Dashboard with product count, stock value, low-stock count and invoice count.
2. Add, edit, delete and search inventory parts.
3. Low-stock status for quantities of 10 or fewer.
4. Create an invoice with multiple spare-part items, quantities and a discount.
5. Validate input and prevent billing more than available stock.
6. Reduce stock after an invoice is created.
7. View basic inventory and sales reports.
8. Print a generated invoice using the browser print option.

## How to run
1. Open the `04_Website` folder.
2. Double-click `index.html` or open it in a modern web browser.
3. No installation or internet connection is required.
4. Data is saved in the same browser using LocalStorage.

## Important notes
- This is an educational front-end mini-project. It does not use a live server or shared database.
- LocalStorage data stays in the browser/device where it was entered.
- The original Class 12 Python/MySQL project inspired this project. The current implementation is a simple HTML/CSS/JavaScript version to meet CSD0111 requirements.
- The sample Excel records are prepared separately for the assignment workbook.
